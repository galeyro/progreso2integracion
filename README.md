# Progreso 2 - Integración - Salud360

## RabbitMQ Docker Compose
Para iniciar el servidor de RabbitMQ, ejecuta en el directorio de la aplicación:

```bash
docker compose up -d
```

### Credenciales por Defecto
* **Host**: `localhost`
* **Puerto AMQP**: `5672`
* **Puerto Consola de Administración (Management Console)**: `15672` (http://localhost:15672)
* **Usuario**: `guest`
* **Contraseña**: `guest`
